### 문자열 자료형

문자로 이루어진 데이터
"",''로 감싸서 표현
예) "안녕", '호호'

### 자료형 확인 - type() 함수

type(데이터 또는 값)

```python
name = "홍길동"
print(type(name))  # <class 'str'>

```


### 이스케이프 시퀀스

역슬래시(\)와 특정 문자를 조합하여
문자열 안에서 특별한 의미를 포함하는 방법

```
\n : 줄바꿈
\t : 탭
\\ : 역슬래시 문자 출력
\' : 작은 따옴표 출력
\" : 큰 따옴표 출력
```

### 여러 줄 문자열 ''' """

파이썬에서
큰따옴표 3개, 작은따옴표 3개로 감싸는건
여러 줄 문자열(Multiline String)

변수에 사용되지 않거나 코드에 사용되지 않으면
아무런 동작안해서 주석처럼 활용할 수도 있음

여러 줄 문자열은
실제로 여러 줄의 텍스트 데이터를 변수에
저장할 때 유용하게 쓰임

코드의 가독성을 위해 문자열을
여러 줄로 나누어 작성하면 """ 또는 '''로
감싼 문자열 안의 줄바꿈도 그대로 포함되어서
출력됨
원하지 않으면 뒤에
**역슬래시(\)** 쓰면 됨
다음줄과 하나의 문장으로 이어서 해석해라

```python
str =
"""
여러줄 주석
줄
바
꿈
도 그대로 출력됨
"""

# 원하지 않으면
text = "안녕하세요 " \
       "반갑습니다."
# text = "안녕하세요 반갑습니다." 이렇게 해석됨
# \쓰면 다음 줄과 하나의 문장으로 이어서 읽어라 의미
```

## 숫자 자료형

숫자를 의미하는 자료형
정수형(Integer), 실수형(Floating-point), 복소수형(Complex)

### 정수형(Integer)

소수점이 없는 꺠끗한 숫자,
-10, 0, 1 처럼 음수, 0, 양수가 해당

### 실수형(Floating-point)

3.14, -0.2222 같은 소수점을 포함하는 숫자를 의미
지수 표현 방식(1.23e134)도 실수형으로 분류됨

### 복소수형(complex)

실수부와 허수부로 구성된 숫자
수학에서는 허수 단위로 i를 쓰지만
파이썬에서는 j를 쓴다고 함
예) 3 + 1j
라고 써야지 파이썬이 해당 숫자를 복소수로 인식한다고
이런 복소수형은 real이라는 속성을 붙여서
실수부만 따로 꺼내거나
imag라는 속성을 붙여서 허수부만 따로 출력해
사용할 수 있다고 함

복소수 = 실수부 + 허수부로 구성

3 → 실수부(real part)
4j → 허수부(imaginary part)

```python
z = 3 + 4j #복소수
print(z.real)# 실수부 조회
#3.0출력

print(z.imag)#허수부 조회
#4.0출력

z = complex(10, 20)

print(z)#(10+20j)
print(z.real)#10.0
print(z.imag)#20.0

# float로 나오는 이유는
# 파이썬 내부에서 복소수와 허수부를 모두
#float로 저장하기 때문

print(type(z.real))#<class 'float'>
print(type(z.imag))#<class 'float'>
```

### None 자료형

이름 그대로 '아무것도 없음'을 의미
보통, 변수를 미리 만들어두어야하는데
당장 넣을 데이터가 없으면 None쓴다함

```python
is_none = None
print(is_none, type(is_none))  # <class 'NoneType'>
```
