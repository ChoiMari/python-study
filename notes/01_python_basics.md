### 변수(variable)

데이터를 저장하는 공간을 의미한다.
프로그램을 작성하다 보면, 숫자나 문자같은 데이터를 저장해두었다가 재사용해야 될 때가 많기 때문에
이때 메모리에 데이터를 저장하고 그 데이터를 이름으로 참조할 수 있도록 하는 것이 변수 개념

### 파이썬에서의 변수 할당(초기화) 방법

변수 이름 = 데이터(값)
예) name = "홍길동", age = 20, is\*student = False

### 파이썬 변수 명명 규칙

파이썬에서 변수 작성 시에는 다음과 같은 규칙을 따른다
변수 이름은 스네이크 케이스(snake case)를 사용
변수명은 영문자, 숫자, \*(언더스코어)로 구성할 수 있음
변수명은 숫자로 시작할 수 없다.(1name 불가)
변수명은 대소문자를 구분한다
변수명은 키워드(예약어) 사용 불가(if,def 등 불가)

### 스네이크 케이스(snake case)

여러 단어로 이루어진 이름에서 단어 사이를 \_로 연결하는 명명 규칙을 말함
예) name_space, user_name, token_passing

### 주석(comment)

마치 메모장처럼 코드에 대한 설명을 남기고 싶을 때나
코드 가리기용으로 사용

\# : 한 줄 주석

"""
여러 줄 주석
"""

'''
여러 줄 주석
'''

파이썬은 공식적으로 # 한 줄 주석만 존재한다

### VSCode에서 주석을 스마트하게 쓰는 법

주석처리하고 싶은 곳에 커서를 두거나 블록잡고
해당 단축키
Windows ) ctrl + /
Mac OS ) cmd + /

다시 누르면 주석 풀림도 됨
